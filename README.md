# Assignment 1 - Java Basics

Java console programs covering variables, input/output, selection, and arrays.
Package: `Assignment1`

## Files
- `Question1.java` - Project Details: displays project name, manager, budget and duration using variables
- `Question2.java` - Bank Account: reads account number, holder name and balance with Scanner, then displays them
- `Question3.java` - Commission Calculator: reads total sales and calculates 2% commission
- `Question4.java` - Promotion Check: reads years of experience, eligible if >= 5 years, else not eligible
- `Question5.java` - Salesperson Sales: reads salesperson name and monthly sales into an array, calculates total and average sales

## Tech Used
- Java (JDK 8+)
- `java.util.Scanner` for user input
- Arrays, loops, if-else

## How to Run
1. Open in NetBeans / VS Code / any Java IDE
2. Make sure all files are in package `Assignment1`
3. Run any question, e.g.:
```bash
javac Assignment1/Question1.java
java Assignment1.Question1
```
Or right-click the file > Run File.

Replace `Question1` with `Question2`, `Question3`, `Question4` or `Question5` to run the others.
